I created this matlab game called Lightbot based on a flash game I played as a kid by the same name. The objective of the game is to get your robot to move to all the blue tiles and light them up, turning them yellow. But, you must input all of the commands such as moving left or right, or lighting up the current tiles before the movement starts. Since there is only a limited number of commands for each level you have to plan the route beforehand. Additionally, later on the loop command is added which repeats all previous commands a set number of times, allowing for much more complexity. The final few levels have multiple lightbots which are all controlled at once, making things even tougher. I made all the sprites for this game myself and had a lot of fun creating it. Since this was the final project for my fundamentals of engineering class I had to use Matlab which presented some challenges but it turned out pretty well in the end.
