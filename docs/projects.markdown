## Vision Lab Projects
I have been working as an undergraduate research assistant at the Ohio State University College of Optometry Binocular Vision Lab since my 2nd year of college. During my time there I've gotten to work on implementing software, hardware, and other technical things to assist with optometry research. Unfortunately I'm unable to share the source code for these projects but each page contains more information about them and pictures or videos showing what they do.
### Line Image Processing
A python script to process hand drawn curves on graph paper and find a curve that matches their drawing using image processing.
[Read More](/line-finder/)

### Blind Walking Paths
For one of our studies, we were investigating the paths people take while walking towards a light in the dark. There were a number of conditions such as seeing the light the whole team or seeing the light only at the start. I did a lot of work on processing this data and trying to model these walking paths including a machine learning model. [Read More](/Blind-Walking/)

### Arduino LED Control
The most complex project I've worked on here. A full stack app with an interactive frontend that controls Arduino boxes to do various LED commands over bluetooth, among other things.
[Read More](/arduino-led-control/)

### VR Stick Study
This project uses VR to adapt a traditional form of vision therapy into a version anyone can do on VR. I worked on improving the VR environment and doing all of the data analysis for the data from our eye tracker.
[Read More](/VR-Stick-Study/)

## Electroscience Lab Research Projects

### MCG Adaptive Noise Filtering
My research group has developed a Magnetocardiography (MCG) sensor for wirelessly detecting heart beats with a magnetic field. The current prototype has been rigorously proven, but still has a very weak signal and only works on subjects sitting perfectly still in a chair. I have been investigating how to use adaptive filtering with an IMU signal to improve the signal integrity and allow for more movement. [Read More](/MCG/)
